# محفظة شبكة الجنرال

سجل ديون شبكة الإنترنت بالدولار: بطاقات، اشتراكات منزلية، مصاريف ورواتب، مناديب، وكشف للمحاسبين.

## الدخول

- المدير والمحاسبون يدخلون **باسم مستخدم وكلمة مرور فقط**.
- الرابط وحده لا يفتح المحفظة.

## الأقسام

- ديون البطاقات
- اشتراكات المنازل
- مصاريف ورواتب
- مدفوعات المناديب (للمدير)
- كشف المحاسبين (للمدير)
- حسابات المحاسبين (حتى 4 محاسبين)

كل حركة تظهر اسم من سجّلها، وعلى حساب أي زبون تمت.

## النسخ الاحتياطي

من داخل المحفظة (بعد الدخول):

1. **نسخ احتياطي** ينزّل ملف JSON فيه كل البيانات بدقة خانتين.
2. **استعادة** (للمدير) تضيف الناقص من الملف ولا تحذف الموجود.

## التشغيل محلياً

يحتاج Node 22:

```bash
npm install
npm run dev
```

التطبيق يعمل على المنفذ 8080. قاعدة البيانات المحلية للتجربة؛ النسخة المنشورة تستخدم قاعدتها الخاصة ولا تُمس بياناتها من هنا.

## ملاحظات

لا تضع كلمات المرور أو ملف النسخ الاحتياطي في المستودع.
